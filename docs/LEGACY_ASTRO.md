# Legacy Astro research console

The original Stratus site was an **Astro** multi-page research console (`src/pages/`, `src/components/directory/`). It was replaced by the **Expo 57** app in `app/` (March 2026).

The Astro UI was removed from this repo; git history retains the old files. Shared data logic remains in `src/lib/` and generated JSON in `src/data/`.

If you need the old static research pages, check out an earlier commit before the Expo migration.
